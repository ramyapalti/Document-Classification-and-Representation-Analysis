# Document-Classification-and-Representation-Analysis
Document classification on the 20 Newsgroups dataset  with approximately 18,000 news posts
Comparative performance analysis of different feature representations

Implemented document representations as Binary Bag of Words (B-BoW) and Context Bag of Words(C-BoW) to train and evaluate Naive-Bayes Multinomial and Naive-Bayes Poisson classifiers

This work is part of CS635 - Information Retrieval and Mining for Hypertext and the Web, offered by Soumen Chakrabarti - IIT Bombay
